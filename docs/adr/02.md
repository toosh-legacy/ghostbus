# ADR 02: Record raw feeds and build everything as replayable streams

- **Status:** accepted (Phase A)
- **Decision:** Record raw feeds and build everything as replayable streams
- **Alternatives:** Process live only
- **Rationale:** Debuggable, reproducible, testable at any speed; enables backfills
