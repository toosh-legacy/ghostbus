# ADR 04: Official arrival/departure records as ground truth

- **Status:** accepted (Phase A)
- **Decision:** Official arrival/departure records as ground truth
- **Alternatives:** Only agency predictions
- **Rationale:** Measures what actually happened; credible to journalists
