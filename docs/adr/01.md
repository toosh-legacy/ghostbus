# ADR 01: Build locally behind interfaces, deploy to Azure by swapping adapters

- **Status:** accepted (Phase A)
- **Decision:** Build locally behind interfaces, deploy to Azure by swapping adapters
- **Alternatives:** Build directly on Azure
- **Rationale:** Fast feedback, $0 development, tests without the cloud
- **Evidence in this repo:** see docs/DECISIONS.md and the eval/backtest reports.
