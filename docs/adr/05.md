# ADR 05: A simulator with exact ground truth for algorithm tests

- **Status:** accepted (Phase A)
- **Decision:** A simulator with exact ground truth for algorithm tests
- **Alternatives:** Only real data
- **Rationale:** Real data has no exact truth for map matching or ghosts
- **Evidence in this repo:** see docs/DECISIONS.md and the eval/backtest reports.
