# ADR 07: DuckDB + Parquet locally, Azure Data Explorer in the cloud

- **Status:** accepted (Phase A)
- **Decision:** DuckDB + Parquet locally, Azure Data Explorer in the cloud
- **Alternatives:** Postgres for analytics
- **Rationale:** Columnar scans for aggregates; same SQL-over-lake pattern
- **Evidence in this repo:** see docs/DECISIONS.md and the eval/backtest reports.
