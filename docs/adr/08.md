# ADR 08: Postgres + PostGIS for operational data

- **Status:** accepted (Phase A)
- **Decision:** Postgres + PostGIS for operational data
- **Alternatives:** A document DB
- **Rationale:** Spatial queries, relational integrity
- **Evidence in this repo:** see docs/DECISIONS.md and the eval/backtest reports.
